# Hospital Analytics Dashboard

Hospital Analytics is an interactive dashboard project developed using Microsoft Excel to analyze hospital and patient data. The dashboard presents important healthcare insights through visualizations and key performance indicators (KPIs), helping users understand patient demographics, medical conditions, hospital admissions, billing patterns, and test results.

### Key Features

* Total patient records
* Average patient age
* Total and average billing amount
* Patient analysis by medical condition
* Gender and blood type distribution
* Admission type analysis
* Insurance provider analysis
* Test result analysis

### Tools and Technologies

* Microsoft Excel
* PivotTables and PivotCharts
* Data Analysis
* Data Visualization
* Interactive Dashboard Design

### Objective

To transform hospital data into meaningful insights through an interactive Excel dashboard, making healthcare information easier to understand and analyze.
